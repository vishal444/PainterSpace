# 3D facial-expression assets

Low-poly, front-facing human busts for PainterSpace. Each expression is a standalone OBJ/MTL pair.

| Asset | Expression cue |
|---|---|
| `happy.obj` | warm open smile |
| `sad.obj` | downturned mouth and inner-raised brows |
| `scared.obj` | wide eyes and small open mouth |
| `grumpy.obj` | lowered brows and narrowed eyes |
| `terrified.obj` | extreme alarm with large open mouth |
| `ecstatic.obj` | closed happy eyes and huge toothy grin |
| `angry.obj` | furrowed brow and tight lips |
| `surprised.obj` | round eyes and startled O mouth |

Coordinate system: Z-up OBJ, face toward -Y, units in meters.
